## Concepts & definitions
- **Breaker (block)** — "this big dump down caused this leg up, we can kind of consider this candlestick a breaker"; he wants price to "push into this breaker block and then push higher". A chat question "failed order block turns into a breaker block" goes unanswered. [05:35]–[06:09]; [15:02]
- **Draws** — relative equal highs = "the first draw to the upside"; an hourly high; an FVG (Gann box); all-time highs. [06:09]–[06:45]; [10:43]
- **Spring / consolidation (Wyckoff, "yops method")** — ES in consolidation; "I would like to see a spring… I need to see this consolidation broken out of". [11:50]
- **Order block fill** — NQ "sweep of these lows, boom order block, fill of the order block, fill of the fair value gap, motion to the upside". [10:43]
- **BTC: buy the consolidation** — in its uptrend, buying each consolidation has been the winning side. [15:37]–[16:46]

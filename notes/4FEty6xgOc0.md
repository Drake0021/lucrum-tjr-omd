## Summary
A re-recording (the original Day 48 had no audio) of TJR's "live testing" on a PPI/core PPI/unemployment claims day he didn't trade: set daily bias for every instrument pre-market, mark building blocks and draws, then paper ("mock") trade. He walks a mock S&P long (15m liquidity sweep on PPI → BOS → retrace into equilibrium → wait for a close back above equilibrium + new BOS → long, stop below sweep, ~1.6R). Key rules: an equilibrium-only entry needs a candle close back above EQ (a single bullish candle inside isn't enough, unlike OB/FVG); intraday trades follow the DAILY trend, not the weekly; never trade daily retraces; trade only when daily/4H/1H align and a LTF counter-move is "primed for execution" into a building block.

## Concepts & definitions
- **Live testing / mock trading** — on a no-trade day: determine daily bias for every pair, mark building blocks, predict where price will draw, set up a mock trade, then review at session end. Best way to build confidence; done in live market conditions. [00:34], [01:08], [13:47]
- **Equilibrium entry confirmation** — when price retraces into equilibrium (50% of the BOS leg), one bullish candle that doesn't close back above the EQ line is "technically bullish confirmation" but NOT enough. For an EQ-only play, wait for a candle to close back above EQ (plus a new BOS over the high). That single candle WOULD be enough if it came into an order block or FVG. [04:25], [04:59]
- **HTF aligned + LTF primed for execution** — daily, 4H, 1H all in the same trend while the 15m breaks structure the opposite way because it is drawing to an hourly building block (e.g., an FVG); that counter-BOS is a retrace of the higher TF and is where you look to execute. [07:42], [08:14]
- **Daily BOS against weekly trend** — usually just causes a weekly retrace into a weekly building block (equilibrium/FVG). [06:36]
- **Bias timeframe for intraday** — use the daily bias (not weekly) because "we're not swing trading, we're doing intraday trades". [08:47], [09:20]

## Rules (model / entry / stop / target / management / filters / risk)
- News filter: no trading on core PPI / PPI / unemployment claims day (FOMC member speech not a concern). [01:08]
- ENTRY MODEL (stated pre-news): wait for liquidity sweep → break of structure → retest into an order block, equilibrium, or fair value gap → reaction off it. [03:50]
- IF entry is equilibrium-only THEN require a candle close back above (for longs) the equilibrium line, ideally with a BOS over the new high, before entering. [04:25], [04:59]
- Stop: underneath the liquidity sweep (for longs). [04:59]
- Targets: 4H candle bodies / highs to the left when little else is available (mock trade; he says he's not very specific with TPs on mock trades). [04:59], [05:31]
- Trade in line with the daily trend; "we never want to trade retraces unless it's on like the weekly time frame" — i.e., don't trade a daily retrace (4H/1H BOS against the daily) as a trade direction. [09:54]
- IF daily bearish, 4H bearish but 1H bullish THEN wait for hourly confirmation (1H BOS down) before shorting; a 15m BOS down while 1H bullish is just a 1H retrace. [07:09], [08:47]
- IF daily bias conflicts with 4H and 1H (e.g., daily bullish, 4H & 1H bearish) THEN don't trade; wait for 4H BOS and 1H BOS back in the daily direction, then look for execution. Meanwhile mark where the daily retrace will draw (FVG, equilibrium, OB) for future longs. [10:27], [11:00], [11:33]
- IF all of weekly/daily/4H/1H align (GU) THEN look for any reason to go in that direction — but still only execute when your marked building block gets hit; if not hit → no trade. [12:07], [13:14]
- Prefers entries off 4H or 1H retracements (longer retracements); a sweep at Forex open with barely a 15m BOS against is not enough. [12:40]

## Process / order of operations
1. Check news calendar; decide whether trading is allowed. [01:08]
2. For each instrument: weekly → daily → 4H → 1H bias. [02:46]
3. Pre-market: mark 15m and hourly lows/highs (liquidity) and HTF building blocks. [03:18]
4. Define the expected sequence (sweep → BOS → retest of OB/EQ/FVG → reaction). [03:50]
5. Execute (or mock) when it occurs; stop beyond the sweep; targets at HTF levels. [04:59]
6. Write the daily bias in notes; at session end review whether predictions were right/wrong and why. [13:47], [14:20]

## Confluences mentioned
- Order block / FVG — a single reaction candle is sufficient confirmation inside these. [04:25]
- Equilibrium — needs close back beyond EQ when used alone. [04:59]
- Weekly equilibrium + weekly FVG as weekly retrace targets. [06:36]
